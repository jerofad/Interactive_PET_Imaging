The model used here

ȳ = A x + s + r
A = κ · diag(n · a) · P
aᵢ = exp(−Σⱼ μⱼ ℓᵢⱼ)
Pᵢⱼ = ℓᵢⱼ in cm

P uses Siddon intersections. κ sets the expected prompt-count budget; n is a prescribed efficiency pattern. Corrections alter A, s and r during reconstruction. The generated measurements stay fixed.

MLEM uses all angles for one update. OSEM partitions angles into interleaved subsets and uses a separate sensitivity for each. More subsets can accelerate early progress; they do not guarantee an equal wall-clock speed-up or monotonic full-data likelihood.

Numerical model, assumptions and verification

What is measured

The brain slice is averaged in 2 × 2 blocks from 128 × 128 to 64 × 64. The simulation uses 120 equally spaced angles over [0, π), with 129 bins at 2 mm spacing. Distances in the projector are in centimetres. This is a 2D parallel-beam simulation with no TOF, detector blur, positron range or PSF model.

All labelled head tissues use a water-equivalent μ = 0.096 cm⁻¹ at 511 keV. This includes the skull in this phase; it is not a calibrated bone μ-map. The cylinder has radius 80 mm. The point is one 4 × 4 mm voxel at (R, A) = (34, 22) mm, not an infinitesimal source.

Prescribed expected prompt fractions are T = 65%, S = 25%, R = 10%. Thus S/(T+S) = 27.78%. These are teaching inputs, not a scanner performance prediction. Scatter uses a broad Gaussian radial profile (σ = 64 mm) with 10% angular modulation; randoms are uniform. Both corrections use the exact simulated expectations and have no estimation uncertainty.

The efficiency is n = 1 + 0.15 cos(2φ) + 0.05 sin(2πb/129), with b the zero-based radial bin. κ = 0.65 N / Σ[n a P xtrue]. There is no decay or dead-time model yet.

What is reconstructed

x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ / (Aᵀ1)
　　　　· Aᵀ[y / (A x⁽ᵏ⁾ + s + r)]

MLEM and OSEM start uniformly in a circular support. Poisson measurements use a seeded product sampler below λ = 10 and transformed rejection above it. Turning noise off supplies the expected sinogram, which can contain fractional counts.

FBP subtracts the enabled additive terms and divides by the enabled multiplicative terms, then applies a spatial Ram-Lak filter and interpolated backprojection. Signed values are retained in calculations. The image display clips below 0 and above 7 a.u.; the caption reports negative pixels.

Post-filtering uses a Gaussian with σ = FWHM / √(8 ln 2), truncated at 3σ with zero boundary padding. It changes the displayed reconstruction and NRMSE; likelihood and deviance are measured before filtering.

Count sweeps run separate seeded acquisitions, not a cumulative event list. Turning corrections off preserves the same measured sinogram and exposure. All work runs in an embedded worker; the page remains self-contained.

Engine verification

Passed 15 checks covering ray lengths, projector adjoint consistency, point-source localisation, cylinder scale, attenuation, correction terms, Poisson sampling and worker cancellation. Noiseless cylinder mean within 30 mm of the centre: MLEM (30 iterations) 0.998, OSEM (3 iterations × 20 subsets) 0.9995, FBP 0.9996 a.u. (assigned: 1). Without attenuation correction, MLEM gives about 0.12 a.u. in the same region. Point sinogram centroid error ≤ 1.00 mm; matched-projector adjoint relative error 3.9e-15.

These figures are reproduced by the project’s automated test suite.
