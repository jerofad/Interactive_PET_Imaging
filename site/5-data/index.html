Model assumptions

Direct pairs join the same detector ring; oblique pairs connect different rings. Maximum ring difference limits accepted obliquity. Odd span groups adjacent ring differences into segments; this toy map also groups by ring-index sum. Compression reduces storage and axial detail. The 3D stack uses nine actual phantom slices from z = −57 to +71 mm; diagram spacing is illustrative. This is a teaching layout, not a vendor sinogram address map. Axial sampling and Michelograms.

Key takeaways

  • A sinogram coordinate (s, φ) identifies one line of response. Each bin holds a line integral of activity.
  • A point source traces a sine curve through the sinogram, which gives it its name.
  • List mode keeps each event’s time and energy. Sinograms are compact but lose that detail.
  • A Michelogram shows which detector-ring pairs are accepted and how they are grouped.
